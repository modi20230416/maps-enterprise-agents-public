# 公开版本说明

本版本提供通用的生产协同框架、合成输入和可重复的离线测试。发布内容不依赖外部业务材料或本机工作目录，所有文档面向首次阅读项目的开发者编写。

公开内容包括 Python 代码、测试、合成场景、非敏感配置模板和技术说明。运行报告、数据库、真实服务配置、API 密钥和训练权重默认不进入版本管理。示例使用保留占位接口；测试凭据为明确的虚构字符串，模型回复为协议夹具。

公开仓库使用独立初始提交，不继承其他工作目录的历史。原始业务附件、沟通记录与历史运行数据不属于本发布内容。

复现实验时产生的文件写入 `artifacts/`。如果自行接入真实订单或设备数据，请审查生成内容后再决定是否共享。Git 忽略规则不等价于对已有提交的清理。

当前没有附加开源许可证。许可证和贡献规则可在维护者确定后单独补充。
